## Dashub

A database management system using ORM, offering AI/ML-driven preventive maintenance and dashboards

### About

This project is a database management system that leverages an ORM for structured data access and manipulation. It integrates AI and machine learning techniques to provide predictive and preventive maintenance insights. The system also features dashboards for data visualization and monitoring, allowing users to track key metrics and trends. The architecture emphasizes efficient data handling, predictive analytics, and clear visual presentation to support decision-making.
